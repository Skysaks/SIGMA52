# Contribuer / Contributing

SIGMA 52 n'est pas un logiciel libre (voir [LICENSE](LICENSE)) : le code est public pour être lu et évalué.

- **Les pull requests ne sont pas acceptées.** Tout code proposé sera fermé sans relecture, pour que la
  propriété de l'œuvre reste à un seul auteur.
- **Les signalements de bugs et les suggestions sont bienvenus** sous forme d'issues : décris le problème,
  le navigateur et l'appareil, et les étapes pour le reproduire. N'y joins jamais tes historiques de mains,
  ta sauvegarde JSON ni des captures de compte.
- **Un chiffre du cours te paraît faux ?** Indique le module, l'exercice ou la question : `test/claims.test.js`
  recalcule les chiffres clés au moteur, l'erreur sera vérifiée de la même façon.
- **Failles de sécurité** : voir [SECURITY.md](SECURITY.md), jamais en issue publique.

En ouvrant une issue, tu acceptes que l'auteur puisse utiliser librement toute suggestion qu'elle contient,
sans obligation ni contrepartie.

*Pull requests are not accepted. Bug reports and suggestions are welcome as issues — never attach hand
histories or personal data. Security issues: see [SECURITY.md](SECURITY.md).*
